# Leaf routines of `Run`: machine-code summaries (agent asm)

Machine-code SUMMARY theorems for the leaf routines `(*bigModExp).Run` reaches (extraction lists:
`/srv/fv-modexp-ops/extract-Run-{arm64,amd64}.log`), on linux/arm64 and linux/amd64, each also a standalone verified row
(`scripts/asm-row.sh ISA Fn SYMBOL`: `janus verify` of an extraction of that function alone, `correctness` +
`Witness.nonvacuous`, under memcap 16G / timeout 900 s).

## How the summaries are meant to be used

* Every summary is proved once on an **Extracted-free library program** `FvModexp.Lib.<Name>.program`
  (`lean/FvModexp/Proofs/Lib/`, generated by `scripts/gen-libprog.py` from `janus extract` of the **pinned harness**,
  `scripts/harness.sha256`): the same bytes at the same absolute addresses as in the extraction of `Run`. A caller
  (e.g. the `Run` row) moves it to its own `Extracted.program` with `Janus.Contracts.EqHashModel.Summary.of_codeIn`
  (arm64) / `Summary.of_codeIn64` (amd64) (fv-uint256 `CodeIn.lean` pattern) and uses it with `janus_run calls [...]`.
* Assembly kernels (`*.abi0`) are `GoABI0.Summary0 program entry Pre Q`: arguments are read from the caller's frame,
  `Q s m` states the memory after the call (result words included) relative to the call state `s`.
  Go (ABIInternal) leaves are `Summary program entry Pre Post` with `Post` either an explicit `s' = { s with regs := … }`
  (cmp) or equations on the result registers (Div64, divWW).
* Values: `FvModexp.Asm.lv m p n = m.readLE p (8 n) = Σ_{i<n} limb_i·2^(64 i)` (model independent). Row statements use
  `readLE` directly (Janus vocabulary only).
* **Model bridge** (`Common/AsmModel.lean`): `limbs m p n : List Nat` (the slice as a mathdiv `nat`), `val_limbs`,
  `Wd_limbs`, `eq_of_val`, and `addVV_model`, `subVV_model`, `mulAddVWW_model`, `addMulVVWW_model`, `cmp_model`
  (result word `= BitVec.ofInt 64 (Mdl.natCmp x y)`): the value-level postconditions imply
  `limbs m' z n = (Mdl.<op> (limbs m x n) …).1` and the carry/borrow `= (…).2`. Summary-level model forms:
  `Arm64/AsmModels.lean` (`addVV_summary_model`, `subVV_summary_model`, `cmp_res_model`), `Amd64/AsmModels.lean`.

## Preconditions and the real call sites (go-bigmodexpfix f9e208c548ab, `src/math/big`)

Aliasing: every slice summary allows `z` **equal to or disjoint from** each input slice (`z = x ∨ Apart z (8n) x (8n)`),
which covers every call site below (in-place calls pass the same base; all others pass separately allocated slices).
Every summary also needs `z[0:n]` disjoint from the result word (amd64: from the whole call frame incl. the return
address), which holds for every Go caller (the frame is the caller's outgoing-argument area).

| nat.cmp | everywhere (`x.cmp(y)`) | read-only; slices may be empty (`len = 0`, any pointer, e.g. nil) |

Other preconditions: lengths are those of `z` (`len(x), len(y) ≥ len(z)` at every call site); the `n` limbs of each
slice must be readable / writable (`Ptr`). For `n = 0` the kernels read nothing but the summaries still ask the
(zero-length) ranges to lie in a region; `nat.cmp` asks nothing of an empty slice. Shift counts: every reachable call
passes `1 ≤ s ≤ 63`.
`nat.cmp` compares **lengths first** (as Go does); it is the value comparison only for normalized inputs
(`cmp_model` + `Mdl.natCmp_spec`).
`Div64` (arm64): `y ≠ 0`, `hi < y`, `GuardOK s 0`, `StackOK s 40 0`. `divWW` (arm64): `y ≠ 0`, `x1 < y`,
`m = reciprocal of y` (as `reciprocalWord` computes), frameless. `divWW` (amd64): the same, args `RAX, RBX, RCX, RDI`,
results `RAX, RBX`; Pre adds the return slot `[RSP]` readable with value `< 2^47`; Post = `Amd64.DivWWSum.Post`
(rip = return address, `RSP + 8`, results, registers outside `RAX..RDX, RSI, RDI, R8..R11` kept, memory, `X15`, FS, DF).

## amd64 `addMulVVWW`: how both paths are covered

`CMPB ·hasADX(SB), $0; JNZ altcarry` reads a runtime global (CPUID-dependent). The summary's precondition only asks the
byte to be readable; `main_lem` runs both branches. MULQ path: 1x loop (`one_lem`) and 4x block (`blk_lem`, executed
limb by limb through the segment lemmas `segM0..3`, which keep the symbolic state small). ADX path: 1x loop
(`aone_lem`), 8x block (`ablock`: four pair-segment lemmas `segA0..3` carrying `RBX` and the `CF`/`OF` chains as one
carry word `W = RBX + CF + OF`, `ablkval` bounds `W < 2^64`), loop `ablk_lem`.

### `hasADX` at the real call sites
The amd64 `addMulVVWW` summary needs the byte `math/big.hasADX` (`.noptrbss`, `Extracted.dataAddr.«…hasADX»` =
`0xbb6b8a` in the pinned harness) to be readable; any value. In the running process the byte is part of the binary's
mapped `.noptrbss` segment (written once by the package initializer from CPUID), so a caller's precondition provides it
like the other writable globals of CONVENTIONS §7: the region holding `0xbb6b8a` readable and the byte outside `R.rt`
(the summary only reads it, so the fact survives every other call). Callers (basicMul, basicSqr, montgomery) must
carry this fact (`GlobalIs`-style: readable + Outside R.rt) in their `CallEnv` extension; no value is assumed, both
code paths are proved.

## `addVW` / `subVW` (both ISAs)
Statement = divmc's `Callees.AddVWEns` shape with three amendments forced by the code (NOTES-divmc.md):
arm64 `above = 40` (the `X3` spill at caller `SP+32`); `zc, xc < 2^63` (the `copy(z[j:], x[j:])` pointers are masked
with `ASR #63` / `SAR $63` of `-(cap - j)`, which equals `if j < cap then p + 8j else p` only for caps below 2^63 — Go caps
always are); `0 < zl → z apart from g+16` (and on amd64 from the TLS slot `fsBase-8`), CONVENTIONS 8c/8d. `VWMoves` =
exactly the `memmove` requests of the `copy` (`R.ok` for each possible `j`). Results: addVW `X0 = (x+y) / B^n`,
`z = (x+y) mod B^n`; subVW `X0 = (n = 0 ? y : [x < y])` (Go's `return y` for empty slices), `z = (x + B^n - y) mod B^n`.
Proof split (one `janus_run` per declaration): `ret0`, `copy` (amd64: `copyA`/`copyB`), `after`/`cont` (memory after
the `memmove`), `rel_store`, `step_inplace`/`step_copy`, `fin1`, `body`, `loop` (induction), `entry_rel`, `ens_lib`
(on the one-segment library program), `ens` (`eq_only` + `MemmoveLive.of_codeIn`), `sum`.

## `lshVU` / `rshVU` (both ISAs)
Pre (frame words `z, len, cap, x, len, cap, s`, result word 7 at `SP+64`/`RSP+64`): `z[0:n]` writable, `x[0:n]`
readable, `1 ≤ s ≤ 63`, lsh: `x ≤ z ∨ Apart`, rsh: `z ≤ x ∨ Apart` (the loop direction makes any such overlap safe),
`z` apart from the result word (amd64: from the whole frame `[RSP, RSP+72)` incl. the return address), `x` apart from the
result word. Results: lsh `Z = (X·2^s) mod 2^(64n)`, `c = (X·2^s) / 2^(64n)`; rsh `Z = X / 2^s`,
`c = (X mod 2^s)·2^(64-s)`. Invariants `LInv` (backward) / `RInv` (forward) in `Common/AsmShift.lean`; amd64 `SHLD`/`SHRD`
appear in Janus as `((hi·2^64 + lo)·2^s) / 2^64` / `(hi·2^64 + lo) / 2^s` (`shld_w`, `shrd_w`).
Proof split (one `janus_run` per declaration): `zero_lem`, `pos_lem`, `one_lem` (1x loop, induction), `h4_lem`,
`blk_lem` (4x loop, induction; the whole 4x body is one run of ~18 instructions), `fin_lem`. Modules 8–13 s, ≤ 2.4 GB.

`reciprocalWord` (arm64): `d1 ≠ 0` (all call sites: natdiv.go:586 `divW`, 655 `divBasic`, normalised top words),
`GuardOK s 48`, `StackOK s 88 0` (own 48-byte frame + `Div64`'s 40), guard word apart from `[SP-88, SP)`; Post
`RecipWordSum.Post`: `X0 = recipWord d1`, SP/R18/g/FP/LR kept, regs outside `X0..X12, X16, X29, X30` kept, memory only
`[SP-88, SP-40)` (tightened in session 3: the caller's saved FP at `SP-8` survives — needed by `divWVW`).

## `divWVW` (both ISAs)
`divWVW(z, xn, x, y)` (natdiv.go:579; reached from `nat.divW`, natdiv.go:564, `divWVW(z, 0, x, y)` with
`len z = len x = m ≥ 1`). Statement (CONVENTIONS §3): `xl = zl`, `y ≠ 0`, `xn < y`, z live and outside the window, x
readable/held/outside the window, `z = x` or apart (the loop writes `z[i]` after reading `x[i]`, descending, so in-place
is safe); result `X0 = (xn·B^n + x) mod y`, `z = (xn·B^n + x) / y`, frame `R.rt ++ winA s 152 72 ++ [z]` (amd64
`win s 64 72`). Window: arm64 own 64 bytes + `reciprocalWord` 88 below `SP`, spills up to `SP+72`; amd64 `PUSH RBP; SUB
$0x30` + the `divWW` return slot (64), spills up to `RSP+72`. Loop invariant (`Common/AsmDivVW.lean`):
`H k = xn·B^(n-k) + x[k:n]`, `r = H k mod y`, `z[k:n] = H k / y` (`H_step`, `dstep`, `digit_lt`, `inv_step`, `q_store`).
Proof split (one `janus_run` per declaration): `fin`, `body` (head → return from `divWW`), `tail` (→ head; the callee's
`MemFrame []` memory is re-read through `hT`), `rel_next`, `val_next`, `loop` (induction), arm64 `gen1` (→ return from
`reciprocalWord`) + `gen2` + `rel_init`, `one1` (→ return from `Div64`) + `one2`; amd64 `gen` (the inlined
`reciprocalWord`: `BSR`, `SHL CL`, mask, `DIVQ`; split on `clz = 0` because the `SHL` by 0 keeps the flags), `one`
(inlined `DIVQ`), `rel_init`; `ens_lib`, `ens`, `sum`. Callees moved into the restricted program by `codeIn_lib`
(arm64, multi-segment `RecipA64`) / `codeIn_single`.

### nat.mulAddWW (natmul.go:136; session 4)
`z.mulAddWW(x, y, r)` with `setWord`, `make`, `norm` inlined. Called by `nat.mul` (natmul.go:26) BEFORE its alias check,
so `z` may be `x`: the pre allows `zp = xp` or `z`'s array apart from `x`. Arguments `[zp, zl, zc, xp, xl, xc, y, r]`
(arm64 `X0..X7`, amd64 `AX, BX, CX, DI, SI, R8, R9, R10`), results `(p', n', c')` (`X0..X2` / `AX, BX, CX`).
* `Pre` (arm64): `CallEnv R L s 4208 72` (frame 112 + the 4096 of the `makeslice` contract; spills up to `SP + 72`) ∧
  `Outside wordT 16 R.rt` ∧ `xl, zc < 2^40` ∧ `NatLive z` ∧ `Outside z (win s 4208 72)` ∧ `(0 < zc → Apart z (g+16) 8 ∧
  (zp = xp ∨ Apart z x))` ∧ x readable / `≤ 2^48` / `Held` / outside the window ∧ `R.inv b L g view` ∧
  `(zc < need → R.ok makeslice [wordT, need, makeCap need] ∧ makeCost need ≤ b)` with
  `need = if xl = 0 ∨ y = 0 then (if r = 0 then 0 else 1) else xl + 1`. amd64: the same with `win s 4208 72` (the CALL's
  return slot at `RSP - 112` is in the window), `g = R14`, `CallEnv` incl. `TlsOK`, and `z` also apart from `[fs-8, fs)`.
* `Post` (amd64 first `s'.fsBase = s.fsBase ∧`): `natVal s'.mem p' n' = natVal s.mem xp xl · y + r` (PRE memory), `NatNorm`,
  `n' ≤ c'`, `n' ≤ xl + 1`, `∃ L' b'`, `LiveExt R L L'`, `b - makeCost need ≤ b'`, `R.inv b' L'`, `NatLive s'.mem R L' p' c'`,
  `(p' = zp ∧ c' = zc) ∨ (InRanges p' (8c') R.rt ∧ ApartAll p' (8c') L)`, `MemFrame (R.rt ++ winA s 4208 72 ++ [z])`
  (amd64 `win`), `LiveFrame L [z]`. Only premise: the live `makeslice` contract.
* Proof split (one module per segment, nat.add's pattern): `MulAddWWDefs` (statement, `mulAddVWW.abi0` moved in by
  `codeIn_vww` + `Summary0.live` → `vww_live` with a reducible `VQ`, `Mid` at the `z.make(m + 1)` join, `Mid.frame0`,
  `Mid.post`), `Norm` (the `norm` loop), `Call` (`tail`: after the call → `z[m] = c` → norm), `Vww` (join → the call; the
  ABI0 post's memory is re-read in `tail`), `Mid` (`mid_of_reuse`, `mid_of_alloc`), `Reuse`, `Alloc` (entry → join),
  `Set` (`SetRel` at the `setWord` block; `setZero`, `setReuse`, `setAlloc` = `make(nat, 1)`), `MulAddWW` (`toSet`,
  `full`, `ens`, `sum`).
